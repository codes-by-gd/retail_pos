# Dashboard

**Status:** 🚧 placeholder page (Phase 0) · real data ⏳ Phase 5
**Purpose:** The day at a glance for the current branch.

## Features
- 🚧 KPI cards: today's sales, bills, average bill value (zero until Phase 5)
- ✅ Low / out-of-stock count for the current branch, linking to the filtered stock page
- ⏳ Gross profit, cash in hand (open register)
- ⏳ Charts: sales trend 7/30 days, payment-method split, top products & categories
- ⏳ Lists: low stock, recent sales, pending customer dues
- ⏳ Branch filter for Admin/Manager (all branches combined)

## Permissions
`dashboard.view`. Figures that reveal profit need `reports.financial`.
